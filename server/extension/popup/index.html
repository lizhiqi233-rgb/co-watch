使用说明
  • 相同房间密码即同一房间；任意成员可发起全员跳转。
  • 首位进房者为房主：播放、暂停、进度、倍速仅房主操作会同步给他人。
  • 部分站点使用自定义播放器时，视频同步可能不准确。
调试日志
